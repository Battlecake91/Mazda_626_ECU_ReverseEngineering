# IC7 HD63B40P Programmable Timer

## Device

`IC7` is an `HD63B40P` programmable timer.

Working address range: `0x2000-0x23FF`.

## Register Select Wiring

| IC7 pin | Signal | Connected address line |
|---:|---|---|
| 10 | `RS0` | `A0` |
| 11 | `RS1` | `A1` |
| 12 | `RS2` | `A2` |

This register-select wiring is now considered confirmed and normal.

## Timer Clock Inputs

| IC7 pin | Function | Connection |
|---:|---|---|
| 4 | `/C2` | Tied with pins 7 and 28, through `F1` to `IC9:5`. |
| 7 | `/C3` | Tied with pins 4 and 28, through `F1` to `IC9:5`. |
| 28 | `/C1` | Tied with pins 4 and 7, through `F1` to `IC9:5`. |

All three timer clock inputs are driven from the divided signal generated by `IC9`.

## Timer Outputs

| IC7 pin | Timer output | Route | Pull-up |
|---:|---|---|---|
| 27 | `O1` | External `C14`, then `IC701:4` on daughterboard | `R85` / `R86` naming conflict exists in notes; verify board marking. |
| 3 | `O2` | External `C15`, then `IC701:5` on daughterboard | `R86` / `R85` naming conflict exists in notes; verify board marking. |
| 6 | `O3` | External `C16`, then `IC701:6` on daughterboard | `R87`. |

Current SE074 notes use:

- `IC701:4 <- IC7:27/O1` via external `C14` with pull-up `R85`.
- `IC701:5 <- IC7:3/O2` via external `C15` with pull-up `R86`.
- `IC701:6 <- IC7:6/O3` via external `C16` with pull-up `R87`.

If earlier notes swap `R85` and `R86`, treat that as a board-silkscreen verification item, not a functional blocker.

## Interrupt Usage

`IC7 pin9 /IRQ` is not connected. Therefore timer events are probably handled by:

- polling timer registers,
- using hardware output pins directly,
- or relying on timer outputs without CPU interrupt service.

This supports the injector-output hypothesis: timer channels can generate pulse timing directly while software configures / arms them.

## External Board Link

`IC7 O1/O2/O3` are routed to `IC701 SE074`, which then drives transistor stages associated with three injector outputs. `IC700` receives a similar group of control lines directly from `IC1`, not directly from `IC7`, which is still one of the most interesting unresolved points.
